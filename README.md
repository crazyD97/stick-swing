# Stick Swing

A 2D Android game made from the DroidPark template.

- Package id: `com.droidpark.stickswing`
- Orientation: portrait

Read `CLAUDE.md` for how the project is organised and `docs/SETUP.md` for machine setup.

```powershell
.\tools\build.ps1 test
.\tools\build.ps1 run
.\tools\build.ps1 phone
```
